Getting started
---------------
ClinicAVT needs Windows 11, an Intel Core Ultra Series 2 processor or later, 16 GB of memory
and about 25 GB of free disk space.

1. Update the Intel graphics driver, using Intel Driver & Support Assistant:
   https://www.intel.com/content/www/us/en/support/detect.html
2. In Intel Graphics Software, set Shared GPU Memory Override to the maximum allowed, then
   restart the computer.
3. If you have the zip version of ClinicAVT, close it and delete its folder. Your consultations
   are kept.
4. Double-click the downloaded .msix file and select Install.
5. Open ClinicAVT from the Start menu.

The first launch takes a few minutes while the models are prepared for this computer. This
happens once. A note model chosen later in Settings is prepared the first time it is used.

To try it without recording, select "Import the file" on the Consultation page and choose
an example consultation. The Help page in the app covers everything else.

If the install fails
--------------------
Check that the drive has enough free space. If Windows is set to install new apps on a second
drive, set it back to the system drive in Settings > System > Storage > Advanced storage
settings > Where new content is saved.

Where your data is kept
-----------------------
Consultations, settings, logs and the prepared models: %LOCALAPPDATA%\ClinicAVT
Guidelines, including any you add: Documents\ClinicAVT guidelines

Uninstalling ClinicAVT from Settings > Apps leaves both folders in place, so a reinstall
starts with your consultations. To remove everything, uninstall ClinicAVT and then delete
both folders.
