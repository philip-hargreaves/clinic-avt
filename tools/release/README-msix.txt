ClinicAVT
---------
Needs Windows 11, an Intel Core Ultra Series 2 processor or later, 16 GB of memory and 25 GB
of free disk space.

1. Update the Intel graphics driver:
   https://www.intel.com/content/www/us/en/support/detect.html
2. In Intel Graphics Software, set Shared GPU Memory Override to the maximum, then restart.
3. Double-click the .msix file and select Install.
4. Open ClinicAVT from the Start menu. The first launch takes a few minutes.

To try it, select "Import the file" and choose an example consultation.

Your data is in %LOCALAPPDATA%\ClinicAVT and Documents\ClinicAVT guidelines. Uninstalling
leaves both folders.
